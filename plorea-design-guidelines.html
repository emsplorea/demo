The Plorea Design System now lives in the repository

This page was the design system's documentation from 2025 until September 2026. It has been moved into Plorea-POS-Frontend, next to the code it describes.

The reason is the reason it had to be corrected so often. A document that lives in a different repository from its code cannot be changed in the same commit, so it drifts — and by the time PLBR-2243 audited it, five documents described this design system and disagreed with each other on almost every point. This page was the most accurate of the five, and it still claimed four themes that no longer existed, named a dozen components that were never built, and carried a WCAG figure that was wrong.

Reading it

From a checkout of the Plorea POS frontend repository: 

npm install
npm run storybook

Start at Design System → Overview. It is a map rather than a document: it links to every rule, states none of its own, and shows a health panel generated from the repository, so its numbers cannot go stale. The theme switcher in the toolbar calls the application's own code, so what you see is what the till does.

What was not moved

Roughly half of this page was deleted rather than carried across, because it described a design system that did not exist:

  • Components that were never built — AppShell, Sidebar, TopBar, KioskShell, PinPad, PBadge, PDialog, PSelect, PAlert, PTabs, KitchenTicket, OrderTimeline. The real list is in Storybook.
  • The Foundation / Wrapped / Domain tiers, retired in favour of Primitives and Patterns, which is what the code has always done.
  • The four Plorea themes — Light, Dark, Dark Dim and Dark Neon. The rebrand replaced them with three Done themes, and the live picker on this page was demonstrating a palette that no longer existed.
  • A token reference, a versioning policy and a CI section that restated — inaccurately — things the repository already enforces in code.

The audit of which sections were unique, which duplicated the repository and which were deleted is recorded on PLBR-2266.
